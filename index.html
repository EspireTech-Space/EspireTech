Questions

Before you write

Short answers to the questions that usually come up in a first conversation.

How long does a typical project take?

A focused website is often a few weeks. A portal or custom tool usually takes longer, because the workflow needs design and review. We propose a timeline after the first conversation, before any build starts.

What do you need from us to start?

A short description of the problem, who will use the software, and any tools you already rely on. A full brief is not required for the first note. The form on this page is enough to begin.

Who owns the code?

You do. We hand over the project files and explain how they are organized, so your team or another developer can continue the work.

How does hosting work?

We prepare the project for the host you choose. A simple site can be published from a GitHub repository. An application may need a host that fits its data and sign-in. We will say which is which in the proposal.

Do you take smaller websites as well as larger software?

Yes. A clear company site and a larger web application are both in scope. The sequence is the same: understand the work, agree the scope, then build.
